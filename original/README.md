# 欧洲三国行程网站

这是一个不依赖服务器和第三方库的单页静态网站。行程内容包含住宿总览、每日时间轴、五家已订酒店、预约、城际交通、应急调整、可勾选检查清单和官方信息入口。

行程内容按2026年9月20日提供的安排更新，所有时间均为当地时间。米兰至佛罗伦萨的列车车次和准确时间，以及卢浮宫、乌菲兹、梵蒂冈博物馆的最终入场时间仍待确认。网站不包含票号、二维码或旅客姓名。

## 本地打开

1. 解压压缩包。
2. 双击 `index.html`。
3. 建议使用最新版 Chrome、Edge、Safari 或 Firefox。

网站可离线阅读。检查清单的勾选状态保存在当前浏览器中；更换设备、使用无痕模式或清除浏览器数据后，进度不会同步。

## 自动定位今天

打开页面时，会按设备的本地日期自动展开、标记并滚动到今天的行程（2026年9月26日至10月8日）。请让手机自动设置日期和时区，抵达欧洲后即按当地日期定位，不需要定位权限。导航栏和日期筛选旁的“回到今天”可清除城市筛选并返回当天。跨天后或跨天重新切回页面会更新；同一天手动浏览其他日期时不会反复跳回。行程前后不自动滚动，也不会把其他年份的同月同日认作今天。

带有 `#hotels` 等章节锚点的链接优先打开指定章节；`#day-2026-09-28` 形式的日期链接可直接展开对应日期。离线使用请同时保留 `today.js`。

## 网页图标

`favicon.ico` 和 `favicon-32.png` 用于浏览器标签页与收藏；`apple-touch-icon.png` 用于 iPhone / iPad 添加到主屏幕。更新已有收藏的图标可能需要清除缓存或重新添加收藏。离线分享时请保留这些资源。

## 目的地天气

保留同目录的 `weather.js`、`weather-ui.js`、`weather.css` 以启用天气功能。天气由浏览器直接获取 Open-Meteo 非商业免费接口，不需要密钥、后端或定位权限。每张日期卡片直接展示对应城市的天气概况、温度范围及降雨概率，收起行程也可查看；没有独立天气面板。缓存有效期30分钟，页面可见时自动检查过期并更新。断网时明确显示缓存与获取时间；空值不显示为0，超过16天的日期等待预报，过去日期不显示旧预报。

每日行程保持离线可读，天气的首次获取和刷新需要联网。公开分享时请保留页面上的 Open-Meteo 署名。修改本目录后，在项目根目录运行 `npm run sync:trip` 同步到 Codex Sites 的 `public/` 镜像，再运行 `npm test` 验证两份资源一致。

## 分享方式

### 直接发送文件

把 `index.html` 发送给对方即可。为了避免聊天软件改名或拦截 HTML，也可以直接发送完整 ZIP 压缩包。

### GitHub Pages

1. 新建一个 GitHub 仓库。
2. 把 `index.html` 上传到仓库根目录。
3. 打开仓库 `Settings → Pages`。
4. Source 选择 `Deploy from a branch`，分支选择 `main`，目录选择 `/ (root)`。
5. 保存后等待 GitHub 生成公开网址。

### Netlify

1. 登录 Netlify。
2. 使用 Netlify Drop 或新建站点。
3. 直接上传包含 `index.html` 的文件夹。
4. 部署完成后即可获得公开网址。

### Vercel

1. 新建一个项目并导入包含 `index.html` 的仓库。
2. Framework Preset 选择 `Other`。
3. 不需要 Build Command，输出目录保持根目录。
4. 部署后即可获得公开网址。

## 打印或导出 PDF

点击网站右上角的“打印 / 导出 PDF”，在浏览器打印窗口中选择“另存为 PDF”。打印样式会自动展开每日行程，并隐藏筛选和操作按钮。

## 内容更新

所有行程数据、样式和交互都位于 `index.html` 内。无需安装 Node.js，也不需要运行构建命令。
